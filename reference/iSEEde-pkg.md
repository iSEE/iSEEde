# iSEE extension for panels related to differential expression analysis

`iSEEde` is a package that provides panels for iSEE, facilitating the
interactive visualisation of differential expression results.

## See also

Useful links:

- <https://github.com/iSEE/iSEEde>

- Report bugs at <https://support.bioconductor.org/t/iSEEde>
